---
title: Getting started
description: Run the Lody Chrome side panel.
---

Requires Node 26 and pnpm 12. Clone with submodules, then install dependencies.

```sh
git submodule update --init --recursive
pnpm install
pnpm dev
```

WXT builds the extension and starts a browser with hot reload. Use `pnpm dev:web` for the same React application in a normal browser. Production output is `.output/chrome-mv3`; load that directory from Chrome's extension developer mode.

The React application serves a primary chat side panel, a lightweight entry popup, settings and a web preview. Hash routing stays inside packaged pages. Lody's own `@lody/ui` is installed as a source workspace dependency and compiled by the shared build plugins. The first release is visibly labeled demo mode; real browser authentication and session transport remain an explicit integration boundary, documented in the repository README.

Run `pnpm check`, `pnpm test` and `pnpm build:storybook` before shipping. See the repository README for the full command map.

---
title: Interaction and design
description: HIG-inspired interaction rules for your own UI.
---

Use Lody's Button, Field, Textarea, Input, Menu, Dialog, Select, Tooltip and feedback primitives with visible keyboard focus, accessible names and readable contrast. Keep the sidebar compact at 360–480px, with a scrollable transcript and fixed multiline composer. Honor IME composition, Shift+Enter, user-controlled reading position and explicit return-to-latest. ThemeRoot owns system/light/dark; small-text contrast overrides live in shared UI themes.

The actual `@lody/ui` workspace owns primitive variants and component APIs; these are re-exported without copying their implementation. The shared UI boundary also owns the locally copied product run-config menu and search field, adapted to controlled extension state. [Shared UI](../../src/shared/ui/README.md) records their upstream sources and accessibility adaptations. Application StyleX primarily owns layout. Icons inherit global Jotai mood from `src/shared/icons`. Ambient shaders are opt-in, disabled under Reduce Motion, and never carry important information.

Use spring transitions as the default for interaction feedback. Add duration-based choreography only when a timed sequence actually requires it. Cuelens currently introduces the app through explicit steps so the user controls reading speed.

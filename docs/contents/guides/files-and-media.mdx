要问合同内容，优先读取带页码的 PDF 文字；要解释图表，附加截图或图片。上传成功只说明资料已传到 Lody，所选模型能否理解它还取决于模型能力。

## 附加普通文件或图片

点击 `+` →「附加图片或文件…」，也可以把文件拖进消息框，或粘贴剪贴板中的图片。核对文件名、预览和状态，写明想完成的任务后发送。例如：「从这份报价单找出付款日期和违约条款。」

文件可在发送前移除。刷新后本机未发送的附件可以恢复；上传部分失败时按界面重试，已确认成功的项会保留。具体大小和类型见 [资料限制](../reference/controls.mdx)。

## 截取可见内容

1. 回到目标网页，点击工具栏 Lody 图标，再打开 `+` →「截图并裁剪…」。
2. 检查截图，框选需要的区域，或使用整张截图。
3. 点击「附加裁剪区域」或「附加整张截图」，再写问题并发送。

截图仅包含当前可见区域，不能自动拼接整页。截图期间保持页面、滚动位置和窗口大小不变；页面变化会使操作取消，回到目标位置后重新截图即可。可见敏感字段可能阻止截图；也请自己检查图像中是否有私人信息。

## 读取 PDF 文字并保留页码

使用 `+` →「其他资料来源…」→「读取 PDF 文字…」，选择本地 PDF。先检查页码和文字预览，再点击「附加带页码的文字」。原 PDF 不会因为文字提取而自动上传。

可以问：「找出第 3–5 页的交付要求，回答时标明页码。」如果需要模型看原始排版或图像，可另外附加 PDF 原文件，并确认所选模型支持它。

扫描件可能只有图片，没有可提取的文字。当前没有 OCR（把图片中的文字识别成可编辑文字的功能），此时可截取目标页作为图片，或先自行提取文字。加密 PDF 需要先在本机解锁。

## 问视频字幕

在有公开字幕的视频页，使用 `+` →「其他资料来源…」→「附加视频字幕」。核对文字和时间戳后问：「列出讲者的三个建议，给出对应时间。」来源预览中的时间定位可回到捕获的页面。

只能读取网页向浏览器公开的字幕。不提供字幕、受保护的视频或没有可读文字时，扩展不会自动转录整段音视频。可以手动附加字幕文件。

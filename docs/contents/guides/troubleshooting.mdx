---
title: 按提示恢复使用
description: 根据失败发生的位置选择下一步。
---

先看侧栏提示发生在哪一步：登录、找助手、读资料、上传，还是确认消息。已经写好的草稿通常会保留；恢复前先核对账户、工作区和来源。

## 发送结果待确认

<Diagram id="delivery" />

出现「发送结果待确认，草稿已保留」时，点击「确认发送结果」。扩展会用原来的发送记录查明送达情况。确认后回到原会话继续；它不会因为你刷新就把同一条问题另建成第二段会话。

等待恢复时不要复制问题到新会话反复发送，避免远端实际已经收到却产生重复任务。确认送达只表示消息已进入会话，还需要等待助手回复。

## 按具体提示处理

| 看见的提示或现象           | 下一步                                                                       |
| -------------------------- | ---------------------------------------------------------------------------- |
| 登录已过期                 | 在设置中重新登录，再核对工作区。                                             |
| 无法验证账户、加载工作区   | 使用「重试登录验证」；网络错误仍存在时保留错误代码。                         |
| 没有连接的机器             | 在电脑上打开 Lody，登录同一工作区。                                          |
| 机器没有可用助手           | 在 Lody 配置 Agent，再选择它。                                               |
| 保存的机器或助手失效       | 新建对话，明确重新选择目标。既有会话不会悄悄改用另一台机器。                 |
| 网站未授权或无法读取       | 重新打开目标网页，附加时核对并授予该网站权限。内部页、受保护页改用可读资料。 |
| 来源标签页已关闭           | 现有快照仍可发送；需要刷新内容时重新打开来源。                               |
| PDF 没有文字或视频没有字幕 | 改用截图、手动提取文字或附加字幕文件。                                       |
| 附件部分失败               | 使用上传恢复或重试，检查失败项；已成功的项会保留。                           |
| 另一个窗口正在发送         | 等它完成，再回到当前草稿发送。不会替你自动把第二份草稿排队。                 |
| 等待批准                   | 核对请求的动作与对象，决定允许或拒绝。                                       |
| 有回复但没有可下载文件     | 仅本机路径无法下载，请助手提供正式附件。                                     |

## 截图失败

回到目标标签页，点击浏览器工具栏里的 Lody 图标后重新尝试。保持标签、滚动和窗口尺寸不变。截图只覆盖可见区域；可见敏感字段、受保护页面或浏览器限制可能阻止读取。

## 安装或更新失败

「扩展更新」检查失败时，可先在浏览器打开发布页，确认网络能访问 GitHub；首次发布前更新源尚不存在。更新源无效或版本回退不会替换已确认的信息。恢复访问后，在设置中点击「检查更新」重试；手动覆盖目录的步骤见 [安装与准备](../tutorial/install.mdx)。

找不到 `manifest.json` 时，确认下载的是发布附件 `lody-chrome.zip`，并选中解压后的 `lody` 文件夹。更新后版本未变，通常是文件复制到了另一个位置：查看 `chrome://extensions` 中原安装的目录，将新版文件覆盖到那里，再对原卡片重新加载。

草稿或设置在更新后消失时，先检查是否加载了第二份 Lody。回到原扩展继续使用，并按 [手动更新步骤](../tutorial/install.mdx) 更新原目录。卸载或清除扩展数据后，本地内容无法通过重新安装恢复。

## 需要进一步定位

打开「选择对话助手」→「连接诊断」，检查账户、连接、能力和发送阶段。诊断可在导出前预览；向维护者说明你想完成的任务、停在哪一步、错误代码以及浏览器版本。

正文资料和原始错误不会被当作完整诊断自动导出。自己追加截图时也先检查内容。网络或服务仍不可用时，保留草稿，恢复连接后再处理原来的发送记录。

你选择的资料会随消息发给 Lody。未发送的草稿留在当前浏览器；已上传附件与云端会话有各自的保留周期。清理本地资料不能代替删除云端内容。

## 权限和偏好

在「设置」的「浏览器访问」中查看、撤销已授予的网站权限以及历史、书签等额外权限。撤销后，后续读取需要重新授权；已经附加的快照或已发送的资料不会因此自动被删除。

扩展会向 GitHub 的公开 Release 更新源及附件域名检查版本信息。检查请求不发送 Cookie、账户令牌、草稿或对话资料；已确认的版本与跳过提醒保存在本机。频率和手动更新步骤见 [安装与准备](../tutorial/install.mdx)。

「个人偏好」由你填写，例如「优先用中文回答，先给结论」。开启后，它作为可见参考随新消息发送。关闭后不再给新消息附加；可另行清除已保存的偏好。扩展不会据此自动学习整段浏览历史。

## 本地与云端

| 内容                         | 保存或发送位置                       | 清理的影响                                             |
| ---------------------------- | ------------------------------------ | ------------------------------------------------------ |
| 未发送文字、来源与附件草稿   | 当前浏览器，按账户、工作区和对话分开 | 本地清理后需重新准备对应资料。                         |
| 上传成功但尚未确认发送的附件 | 可能已经在附件服务                   | 取消、移除或清理本地记录不代表云端附件删除。           |
| 已发送问题、资料与回答       | Lody 会话及附件服务                  | 删除云端会话需等待确认；服务端附件保留与回收另有边界。 |
| 个人偏好                     | 本机保存；开启后随消息发送           | 关闭影响未来消息，不改写已经发送的历史。               |
| 公开分享                     | 独立的已发布快照                     | 撤销影响后续访问，不收回读者保存的副本。               |

在「本地资料」中可清理未发送附件。退出此设备会清除本机登录凭证和未发送的二进制附件；不会删除云端会话。当前不能确认本地清理会让附件服务一并删除所有已上传文件。需要远端清理时，请向服务维护者确认保留和删除方式。

## 发送前需要检查什么

网页读取会排除隐藏、表单和编辑区等内容，并过滤标记为敏感的区域，但普通正文仍可能包含个人信息。发送前检查来源预览、文件与截图；不要把过滤当成绝对保证。

语音输入使用浏览器提供的语音识别。它可能调用浏览器的在线服务；不希望使用该服务时继续输入文字。扩展不会默认保存原始音频。

当前不开放无痕安装，也没有组织策略管理入口。功能范围见 [可用能力与限制](./availability.mdx)。

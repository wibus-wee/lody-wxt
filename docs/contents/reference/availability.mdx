---
title: 可用能力与限制
description: 区分扩展已提供的入口和仍需服务或协议支持的能力。
---

当前扩展适合网页旁的资料问答、会话管理和提示词复用。下表描述当前扩展版本的入口；账户、运行机器、模型和部署服务决定实际可用性。

## 可通过扩展完成

| 场景               | 可用路径                                     | 使用边界                                           |
| ------------------ | -------------------------------------------- | -------------------------------------------------- |
| 网页问答、多页比较 | 手动来源、发送时读取、标签页选择             | 正文有限长度，可能只覆盖部分内容。                 |
| 图片和文档问题     | 文件、截图、PDF 文字、公开字幕               | 模型能力不同；扫描 OCR 与无字幕转录未提供。        |
| 持续对话和管理历史 | 继续、搜索、编辑、重新生成、分叉、归档、删除 | 消息操作以运行助手声明的能力为准。                 |
| 复用提示词         | 同步快捷指令、`/`、`$`                       | 需要资源授权；跨设备更新可能略有延迟。             |
| 定时任务           | 创建、启停、手动请求、查看记录               | 需要支持定时任务的在线机器；不是浏览器本地定时器。 |
| 导出与公开分享     | Markdown、预览后发布                         | 分享需要配置服务；普通文件附件不进入公开分享。     |
| 听写和任务通知     | 能力检测后显示入口，用户主动开启             | 浏览器语音支持不同；浏览器关闭时扩展不检查通知。   |

## 尚未开放

助手不能通过当前扩展点击、输入、提交网页或管理任务标签组，也不能把文件注入网站上传框。录制重放、浏览器调试工具通道、密码管理器自动填充和组织策略管理都尚未接入。

这也意味着：把网页加入问题，是把资料交给助手理解，不会授权它操作那个网站。

## 浏览器和设备

发布包面向桌面 Chrome，通过 GitHub Releases 下载、本地解压安装和手动更新。Firefox 构建仅供开发验证，尚未提供经过发布验收的安装包。Edge、Brave、Vivaldi、Opera 尚未独立验证；Safari、手机浏览器、商店安装和企业部署尚未提供。安装和更新步骤见 [安装与准备](../tutorial/install.mdx)。

会话、附件和快捷指令复用 Lody 的服务，不要求先链接 Desktop UI。运行对话与定时任务仍需要合适的在线机器。不同部署的服务配置可能不同，未发送的本地草稿也不会跨设备同步。遇到不可用的入口，先检查界面给出的原因；需要配置服务时联系维护者。

## 操作入口

| 入口                   | 作用                                             |
| ---------------------- | ------------------------------------------------ |
| 浏览器工具栏 Lody 图标 | 打开侧栏。没有侧栏能力的环境可能打开扩展页面。   |
| 右键 Lody 入口         | 把触发时的页面、选区、链接或图片带到确认界面。   |
| 会话列表 / 新建会话    | 打开历史或开始本地新草稿。                       |
| 设置                   | 登录、选择工作区、外观、隐私、通知与高级工作区。 |
| 选择对话助手           | 选择运行机器与 Agent；已有会话保持原目标。       |
| 当前页面               | 显式开启发送时读取当前标签页。                   |
| 标签页                 | 选择一张或多张已打开页面并附加。                 |
| `+`                    | 附加图片或文件、截图并裁剪、其他资料来源。       |
| 选择工具               | 查看技能与工作区 MCP 目录，选择本次工具。        |
| 快捷指令与定时任务     | 管理复用提示词和计划。                           |
| 语音输入（可用时）     | 主动听写，审阅后加入草稿；不会自动发送。         |

MCP 是助手连接外部工具的一种方式。你需要关注连接是否真正可用：目录中有名称，不等于运行机器已经连接成功；安装与授权在 Lody 中管理。

## 按键

| 按键                                | 效果                                                 |
| ----------------------------------- | ---------------------------------------------------- |
| `Alt+Shift+L`                       | 默认打开或聚焦侧栏；可在浏览器扩展快捷键设置中修改。 |
| `Enter` / `Shift+Enter`             | 发送 / 换行。输入法正在选字时不会因此发送。          |
| `/` / `@` / `$`                     | 在光标处搜索命令与快捷指令 / 会话与标签页 / 技能。   |
| 候选中的方向键 / `Enter` / `Escape` | 选择 / 确认候选 / 关闭候选。确认候选不等于发送。     |

## 资料上限

| 资料         | 当前限制                                       | 超出时怎么做                                   |
| ------------ | ---------------------------------------------- | ---------------------------------------------- |
| 消息输入     | 16,000 个字符                                  | 缩小问题或分次发送。                           |
| 网页资料     | 最多 8 份，每份最多保留 12,000 个字符          | 移除来源、选择目标段落，检查截断提示。         |
| 普通文件     | 每个不超过 100 MiB（约 105 MB）                | 减小或拆分文件；可用类型以选择和校验提示为准。 |
| 图片         | 每张不超过 5 MiB（约 5.2 MB），一次最多 8 张   | 压缩或裁剪。支持 PNG、JPEG、WebP、GIF。        |
| PDF 文字提取 | 25 MiB（约 26 MB）、100 页、120,000 个字符以内 | 核对预览的截断和无文字页，按需要拆分。         |
| 历史搜索     | 1–30 天，最多显示 50 条                        | 缩小日期、关键词或域名范围。                   |

资料被读取或上传，不保证所选模型能理解它。PDF 文字提取不含 OCR；截图不含整页滚动拼接。

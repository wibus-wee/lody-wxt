description: 下载发布包，在 Chrome 本地解压安装，并在新版本发布后手动更新。

从 [最新版本发布页](https://github.com/wibus-wee/lody-wxt/releases/latest) 下载 **lody-chrome.zip**，即可在 Chrome 本地解压安装。普通使用不需要下载源码，也不需要安装 Node 或 pnpm。当前通过 GitHub Releases 分发，本地安装需要手动更新。其他浏览器的情况见 [可用能力与限制](../reference/availability.mdx)。

已经安装？直接继续 [发出第一条网页问题](./first-conversation.mdx)。

## 1. 下载并加载扩展

1. 在发布页的 **Assets** 中下载 **lody-chrome.zip**。不要选择 **Source code**；那是源码，不是可安装的扩展。如果最新版本页面不存在或没有这个附件，该版本尚未完成发布。
2. 解压 ZIP，把其中的 **lody** 文件夹放到一个固定位置，例如用户目录下的 `LodyExtension/lody`。文件夹内应直接包含 `manifest.json`，包内的 `INSTALL.md` 可随时查阅。保留这个位置，不要在安装后删除或移动文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择 **lody** 文件夹，而不是 ZIP 或它的上一级目录。Lody 应出现在扩展列表中，版本号应与发布页一致。
5. 在浏览器扩展菜单中找到 Lody，把它固定到工具栏。点击图标，应打开 Lody 侧栏。也可以使用 `Alt+Shift+L`；快捷键冲突时，在 `chrome://extensions/shortcuts` 调整。

如果浏览器由组织管理且不允许本地加载，请联系管理员确认安装方式。

ZIP 只是解压安装包，不能通过双击或拖入 Chrome 直接安装。加载失败时，先确认选中的文件夹内有 `manifest.json`，且下载的是上述发布附件。

## 2. 准备运行助手的机器

侧栏需要把问题交给一台已经在 Lody 中连接的电脑。让那台电脑保持在线，在 Lody 登录你的账户、选择工作区，并确保已配置至少一个 Agent。Agent 是实际处理问题的助手配置；没有它，浏览器只能准备草稿，不能生成回答。

机器可以与浏览器在同一台电脑，也可以在其他设备。浏览器和机器必须使用同一工作区。进入下一篇练习后，你会在侧栏选择它们并发出第一条问题。

## 3. 手动更新

扩展每 6 小时检查稳定版更新源，发现新版时，设置图标右上角会出现一个小标记。悬停或用键盘聚焦图标可查看版本提示；不会自动弹出或改变聊天区域。打开「设置 → 扩展更新」，也可以立即「检查更新」，查看当前版本、更新日志和新版 ZIP 下载入口。「跳过此版本」隐藏该版本的小标记；更高版本会重新提示，手动成功检查也会恢复标记。检查失败时会在设置页显示错误，保留上次成功确认的信息。

检查更新不会自动下载或安装。`chrome://extensions` 上的「更新」按钮也不会替你下载 GitHub 发布包。更新源首次成功发布后才可用；无法访问时，可以直接查看 [最新版本发布页](https://github.com/wibus-wee/lody-wxt/releases/latest)。

1. 如有「发送结果待确认」，先按界面恢复原消息；保存正在编辑的重要文字，再关闭 Lody 侧栏和设置页。
2. 下载新版 **lody-chrome.zip**，先解压到临时位置。核对发布页版本和包内 `lody/manifest.json` 的 `version`。
3. 将新版 **lody** 文件夹中的全部内容复制到**原来加载的 lody 文件夹内**，覆盖同名文件。保留原文件夹的完整路径；不要让文件变成 `lody/lody/manifest.json`。不要卸载扩展或清除扩展数据，这会丢失本地草稿、设置和待确认的发送记录。
4. 打开 `chrome://extensions`，对原来的 Lody 卡片点击「重新加载」图标。确认版本已更新、扩展 ID 未变，再点击工具栏图标打开侧栏。
5. 核对登录、工作区和草稿。已有的待确认发送继续按原记录恢复，再开始新问题。

不要把新版本从另一个目录「加载已解压的扩展程序」：它可能成为另一份独立安装，原安装的本地数据不会自动迁移过去。

需要回退时，从 [全部发布版本](https://github.com/wibus-wee/lody-wxt/releases) 下载之前的包，用相同步骤覆盖原目录并重新加载。回退前备份重要文字；旧版本不保证能读取新版本保存的全部状态。

拿到维护者提供的 Chrome 扩展构建包后，可以在本机加载 Lody。本指南适用于 Chrome；当前没有经过发布验收的商店安装入口。其他浏览器的情况见 [可用能力与限制](../reference/availability.mdx)。

已经安装？直接继续 [发出第一条网页问题](./first-conversation.mdx)。

## 1. 加载扩展包

1. 解压构建包，找到包含 `manifest.json` 的文件夹。这个文件用于让浏览器识别扩展；稍后选择它所在的文件夹即可。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」。这是 Chrome 的本地扩展加载入口，这次用它安装尚未上架的版本。
3. 点击「加载已解压的扩展程序」，选择刚才的文件夹。保留这个文件夹，不要在加载后删除它。
4. 在浏览器扩展菜单中找到 Lody，把它固定到工具栏。点击图标，应打开 Lody 侧栏。

如果浏览器由组织管理且不允许本地加载，请联系管理员确认安装方式。

没有构建包时，向维护者索取；构建源码的步骤另见 [开发起步](../dev/getting-started.mdx)。普通使用不需要运行仓库命令。

## 2. 准备运行助手的机器

侧栏需要把问题交给一台已经在 Lody 中连接的电脑。让那台电脑保持在线，在 Lody 登录你的账户、选择工作区，并确保已配置至少一个 Agent。Agent 是实际处理问题的助手配置；没有它，浏览器只能准备草稿，不能生成回答。

机器可以与浏览器在同一台电脑，也可以在其他设备。浏览器和机器必须使用同一工作区。进入下一篇练习后，你会在侧栏选择它们并发出第一条问题。

<details>
<summary>更新扩展后需要做什么？</summary>

用新的构建包更新本地扩展文件，在 `chrome://extensions` 对 Lody 点击重新加载。再次打开侧栏，核对登录和工作区；如果有待确认的发送记录，先按界面恢复原消息，再继续提问。

</details>
